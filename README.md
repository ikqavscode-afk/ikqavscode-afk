## 🗂️ Описание проектов

### 1. QAxRayTest — платформа базового тестирования сайтов и API

**Стек:** Python · Flask · Pydantic · requests · pytest · ruff · mypy · GitHub Actions

Приложение с веб-интерфейсом и консольной командой: вводите адрес сайта, подтверждаете право на его тестирование и получаете результат стандартного набора проверок.

Что реализовано:

* Защита от запросов к внутренним сетям (SSRF): проверка адреса, DNS-ответов и каждого перенаправления.
* Безопасный HTTP-клиент с лимитами по времени и размеру ответа и повтором только при сетевых сбоях.
* Расширяемая архитектура: новая проверка добавляется отдельным классом, сбой одной проверки не останавливает запуск.
* Единый словарь статусов: PASSED, FAILED, WARNING, SKIPPED, BLOCKED.
* 116 автотестов без обращения к сети, проверки качества кода и CI.

🔗 [Открыть проект QAxRayTest](https://github.com/ikqavscode-afk/QAxRayTest)

### 2. qa-test-documentation — портфолио по ручному тестированию

**Стек:** Markdown · Python · GitHub Pages · GitHub Actions

Тестовая документация по нескольким веб-проектам и интерактивные тренажёры.

Что внутри:

* Чек-листы, тест-кейсы, баг-репорты и итоговые отчёты о тестировании.
* Тренажёры: классы эквивалентности и граничные значения, таблица принятия решений, «найди баг», проверка качества баг-репорта.
* Генерация документации и данных из Python-скриптов, автоматическая проверка в CI.

🔗 [Открыть проект qa-test-documentation](https://github.com/ikqavscode-afk/qa-test-documentation) · [Сайт с тренажёрами](https://ikqavscode-afk.github.io/qa-test-documentation/)
