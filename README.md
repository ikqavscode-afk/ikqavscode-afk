## 🗂️ Проекты

### 1. Flask_Project — дневник с карточками, опубликованный в интернете
`Python` `Flask` `SQLAlchemy` `Alembic` `PostgreSQL` `Docker` `pytest` `Ruff` `GitHub Actions` `Render`

Сборник проектов на Python. Главный из них — **Flask Diary**: веб-приложение для личных заметок в виде карточек, доведённое до состояния, пригодного для выпуска. Рядом лежат блог на Flask, алгоритмы динамического программирования и консольный магазин.

**Что реализовано**
- Регистрация и вход, личные карточки, поиск, постраничный список, подтверждение удаления в доступном окне.
- Безопасность: пароли хранятся в виде хеша, формы защищены от CSRF, ограничено число попыток входа, включена строгая политика содержимого (CSP) и другие защитные заголовки.
- Миграции базы, работа на SQLite и PostgreSQL, запуск в Docker.
- Около 416 автотестов (в Diary 259, покрытие 99%), нагрузочный скрипт, проверки доступности. Lighthouse: Accessibility 100, Best Practices 100.
- CI: 12 проверок на каждом pull request (линтер, форматирование, тесты на разных версиях Python, PostgreSQL, Docker, аудит зависимостей), основная ветка защищена.
- Эксплуатация: проверка доступности каждые 10 минут, ежедневная зашифрованная копия базы с автоматической проверкой восстановления, документация по публикации и откату.

🔗 [Репозиторий](https://github.com/ikqavscode-afk/Flask_Project) · 🌐 [Работающий пример](https://flask-diary-vwos.onrender.com) (бесплатный тариф: после паузы сервис просыпается около минуты)

### 2. Training_tools_Python — практикум по алгоритмам и структурам данных
`Python` `pytest` `Ruff` `Mypy` `GitHub Actions` `GitHub Codespaces`

Репозиторий-практикум: короткая теория простыми словами, задания с автопроверкой, подсказки трёх уровней, эталонные решения и «интересные факты». Открывается в браузере через Codespaces, ничего устанавливать не нужно.

**Что реализовано**
- 8 основных модулей (48 заданий): поиск, простые сортировки, рекурсия и стек, быстрая сортировка, очередь и сортировка слиянием, хэш-таблицы, деревья (BST, AVL), графы.
- 3 бонус-уровня (24 задания): инструменты профи (декораторы, генераторы, `lru_cache`, `bisect`, `heapq`), качество кода (`@dataclass`, рефакторинг, мини-линтер, код-ревью), инженерное мышление (замеры, поиск причины, декомпозиция, оценка сроков).
- 372 автотеста; CI проверяет линтер, типы, эталонные решения и то, что заготовки остаются нерешёнными; таблица прогресса в GitHub Actions; релизы v0.1.0–v1.3.0.

🔗 [Репозиторий](https://github.com/ikqavscode-afk/Training_tools_Python)

### 3. QAxRayTest — платформа базового тестирования сайтов и API
`Python` `Flask` `Pydantic` `requests` `Selenium` `pytest` `ruff` `mypy` `GitHub Actions`

Приложение с веб-интерфейсом и консольной командой: вводите адрес сайта, подтверждаете право на его тестирование и получаете результат стандартного набора проверок.

**Что реализовано**
- Защита от запросов к внутренним сетям (SSRF): проверка адреса, DNS-ответов и каждого перенаправления.
- Безопасный HTTP-клиент с лимитами по времени и размеру ответа и повтором только при сетевых сбоях.
- Расширяемая архитектура: новая проверка добавляется отдельным классом, сбой одной проверки не останавливает запуск.
- Единый словарь статусов: PASSED, FAILED, WARNING, SKIPPED, BLOCKED.
- 25 проверок: доступность и HTTP, структура страницы, навигация, API по `GET`-путям, браузерные проверки; отчёты для Allure и bug report.
- Более 700 тестовых функций (юнит-, интеграционные и браузерные), проверки качества кода и CI.

🔗 [Репозиторий](https://github.com/ikqavscode-afk/QAxRayTest)
