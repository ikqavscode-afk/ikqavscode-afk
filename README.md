## 🗂️ Описание проектов

### 1. Training_tools_Python — практикум по алгоритмам и структурам данных

**Стек:** Python · pytest · Ruff · Mypy · GitHub Actions · GitHub Codespaces

Репозиторий-практикум: короткая теория простыми словами, задания с автопроверкой, подсказки трёх уровней, эталонные решения и «интересные факты». Открывается в браузере через Codespaces, ничего устанавливать не нужно.

Что реализовано:

* 8 основных модулей (48 заданий): поиск, простые сортировки, рекурсия и стек, быстрая сортировка, очередь и сортировка слиянием, хэш-таблицы, деревья (BST, AVL), графы.
* 3 бонус-уровня (24 задания): инструменты профи (декораторы, генераторы, `lru_cache`, `bisect`, `heapq`), качество кода (`@dataclass`, рефакторинг, мини-линтер, код-ревью), инженерное мышление (замеры, поиск причины, декомпозиция, оценка сроков).
* 372 автотеста, CI проверяет линтер, типы, эталонные решения и то, что заготовки остаются нерешёнными; таблица прогресса в GitHub Actions; релизы v0.1.0–v1.3.0.

🔗 [Открыть проект Training_tools_Python](https://github.com/ikqavscode-afk/Training_tools_Python)

### 2. QAxRayTest — платформа базового тестирования сайтов и API

**Стек:** Python · Flask · Pydantic · requests · Selenium · pytest · ruff · mypy · GitHub Actions

Приложение с веб-интерфейсом и консольной командой: вводите адрес сайта, подтверждаете право на его тестирование и получаете результат стандартного набора проверок.

Что реализовано:

* Защита от запросов к внутренним сетям (SSRF): проверка адреса, DNS-ответов и каждого перенаправления.
* Безопасный HTTP-клиент с лимитами по времени и размеру ответа и повтором только при сетевых сбоях.
* Расширяемая архитектура: новая проверка добавляется отдельным классом, сбой одной проверки не останавливает запуск.
* Единый словарь статусов: PASSED, FAILED, WARNING, SKIPPED, BLOCKED.
* 25 проверок: доступность и HTTP, структура страницы, навигация, API по `GET`-путям, браузерные проверки; отчёты для Allure и bug report.
* Более 700 тестовых функций (юнит-, интеграционные и браузерные тесты), проверки качества кода и CI.

🔗 [Открыть проект QAxRayTest](https://github.com/ikqavscode-afk/QAxRayTest)

### 3. qa-test-documentation — портфолио по ручному тестированию

**Стек:** Markdown · Python · GitHub Pages · GitHub Actions

Тестовая документация по пяти учебным проектам и интерактивные тренажёры.

Что внутри:

* Чек-листы, тест-кейсы, баг-репорты и итоговые отчёты о тестировании.
* Тренажёры: классы эквивалентности и граничные значения, таблица принятия решений, «найди баг», проверка качества баг-репорта.
* Генерация документации и данных из Python-скриптов, автоматическая проверка в CI.

🔗 [Открыть проект qa-test-documentation](https://github.com/ikqavscode-afk/qa-test-documentation) · [Сайт с тренажёрами](https://ikqavscode-afk.github.io/qa-test-documentation/)
