🚀 Избранные проекты

1. UI Automation — сервис «Самокат»

"Открыть репозиторий →" (https://github.com/ikqavscode-afk/Sprint_6)

Проект автоматизации тестирования пользовательского интерфейса учебного сервиса.

Что проверяется:

- отображение ответов в разделе «Вопросы о важном»;
- оформление заказа через разные кнопки;
- сценарии оформления заказа с различными данными;
- переходы по логотипам сервиса и Яндекса.

Технологии: Python, pytest, Selenium, Allure, Page Object Model.

В README проекта описано 14 тестовых сценариев. В коде выделены страницы, тесты и общие настройки запуска.

2. UI Automation — Stellar Burgers

"Открыть репозиторий →" (https://github.com/HugoxRay/Sprint_5)

Набор UI-автотестов для проверки основных пользовательских сценариев приложения.

Что проверяется:

- регистрация пользователя;
- вход в аккаунт разными способами;
- переходы в личный кабинет и обратно в конструктор;
- выход из аккаунта;
- навигация по разделам конструктора.

Технологии: Python, pytest, Selenium, Google Chrome.

3. Flask Diary — веб-приложение

"Открыть репозиторий →" (https://github.com/ikqavscode-afk/flask)

Учебное веб-приложение для работы с карточками дневника.

Реализованная функциональность:

- регистрация и авторизация;
- проверка пользовательских данных;
- работа с карточками и записями;
- хранение данных в SQLite;
- HTML-шаблоны и CSS-оформление.

Технологии: Python, Flask, Flask-SQLAlchemy, Flask-Login, SQLite, HTML, CSS, pytest.

4. Flask Blog — заметки и пользователи
